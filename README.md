
# 🏎️ CarsUniverse

**Explorando o universo dos carros, dos personagens às pistas.**

O CarsUniverse é um projeto individual desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas da SPTech School**. Inspirado pelo meu interesse por automóveis e por filmes que marcaram minha infância, como *Carros*, o projeto busca reunir informações e experiências interativas relacionadas a esse universo.

## 🎯 Objetivo

Desenvolver uma plataforma web informativa e interativa que permita aos usuários explorar conteúdos sobre o universo automobilístico e o filme *Carros*, além de testar seus conhecimentos por meio de quizzes e acompanhar seus resultados.

## ✨ Funcionalidades

- **Exploração do universo:** páginas com informações sobre personagens, locais e outros elementos relacionados ao tema.
- **Cadastro e login:** criação de contas e autenticação de usuários.
- **Quizzes interativos:** questionários para testar conhecimentos sobre os conteúdos apresentados.
- **Dashboard:** visualização dos resultados e acompanhamento do desempenho nos quizzes.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- MySQL

## 📚 Objetivo acadêmico

O projeto tem como finalidade aplicar, na prática, os conhecimentos adquiridos durante a graduação, envolvendo desenvolvimento web, lógica de programação, integração com banco de dados e criação de funcionalidades interativas.

Além do aprendizado técnico, o CarsUniverse representa a oportunidade de transformar um interesse pessoal em um projeto próprio, unindo criatividade, tecnologia e desenvolvimento contínuo.
